# Fixture policy

Do not commit sensitive, proprietary, or live malware samples casually.

Unless a record states otherwise, repository-authored synthetic fixtures are
dedicated under [CC0 1.0 Universal](LICENSE-CC0). The license does not override
third-party terms recorded for externally sourced fixtures.

Fixture classes:

- generated canonical patterns with deterministic seeds;
- small freely redistributable format samples with recorded license/source;
- malformed cases minimized from fuzzing;
- synthetic sparse and huge virtual sources;
- separately managed restricted corpus referenced by digest only.

Every fixture record should include digest, license, expected structural properties, allowed distribution, and which tests consume it.
