# Strata 0.1.0

Strata 0.1.0 is the first public pre-alpha preview of the linked binary visual
analysis workbench.

## Download

Download `Strata-0.1.0-arm64.dmg` from the assets below. This build requires an
Apple Silicon Mac running macOS 15 or newer.

The DMG is hardened, Developer ID signed, Apple notarized, stapled, and accepted
by Gatekeeper. It contains `Strata.app`, an Applications shortcut, and copies of
the MIT and Apache-2.0 licenses.

The release also provides `Strata-0.1.0-sbom.zip`, containing target-specific
CycloneDX 1.5 JSON documents for all 18 workspace crates, plus its own adjacent
SHA-256 checksum file.

Verify the download with the adjacent checksum file:

```bash
shasum -a 256 -c Strata-0.1.0-arm64.dmg.sha256
```

Expected SHA-256:

```text
1254d1c2ff27e32ac78596e878afcfcce605c7d3c8f7d65722b0ed995febdc39
```

The expected SHA-256 for the SBOM bundle is:

```text
9560151c8f8f1a882056ba0af318f66bb2a54f4b1a37cd6d2a3387b724cb0785
```

## Highlights

- Read-only local file opening with bounded reads and progressive SHA-256.
- Linked Structure, Grammar, Resonance, Interleave, Revision diff, Discover,
  and 3D Lab workflows.
- Raster, Hilbert, transition, bit-plane, complexity, section, alignment,
  recurrence, spectrum, Hamming, hierarchy, and address-path projections.
- Exact or disclosed sampled byte provenance for rendered data and findings.
- String, repetition, periodicity, correlation, signature, and reversible XOR
  discovery evidence.
- WGPU/Metal Alignment and Hamming coordinate kernels with CPU differential and
  fallback.
- Source-free sessions, private local project locators, programmable video
  exports, and JSON provenance sidecars.
- Strict UFSC `0.1.x` signature-pack adapter with rejection accounting and
  candidate-evidence semantics.

## Known limitations

- Pre-alpha: formats, UI, and compatibility promises can change.
- Apple Silicon and macOS 15+ are the only accepted release target.
- The app is notarized but not sandboxed or independently audited.
- Third-party plugin installation, update delivery, and broad GPU acceleration
  are not implemented.
- Heuristics and signatures are evidence cues, not malware, encryption,
  compression, or file-type verdicts.
- A separate clean-machine acceptance pass remains desirable beyond the local
  quarantine and first-launch tests used for this artifact.

See the [README](https://github.com/a-Gb/strata#readme),
[implementation status](https://github.com/a-Gb/strata/blob/v0.1.0/docs/20-implementation-status.md),
and [security policy](https://github.com/a-Gb/strata/security/policy) before
using Strata with hostile or sensitive material.
